## Earthy

This is a basic website using NASA's API key that give's a image, description of what's being shown and the title. (You can get the API at https://api.nasa.gov/ !) 

## Here are a few features: 
- NASA image displayed for each day that has passed
- Date picker so you can select the image you want to see :D
- Short description + title off the image displayed
